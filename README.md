# QBili（轻哔）

基于 **Kotlin + Jetpack Compose + Material 3** 的 B 站第三方 Android 客户端，采用单模块工程、手写依赖注入和分层架构。

> **非官方项目**：本项目与哔哩哔哩及其关联公司不存在隶属、合作或授权关系。功能仍在持续开发，接口变更或平台风控可能导致部分功能不可用。使用前请阅读 [免责声明](DISCLAIMER.md)。

## 功能

- **首页推荐**：在「我的 → 设置 → 推荐算法」切换网页端／App 端推荐，选择保存在本机，切换后自动替换旧列表并回顶；支持分页、下拉刷新及再次点击首页回顶／刷新。
- **推荐屏蔽**：按标题关键词、Tag、频道和 UP 主过滤推荐；独立管理屏蔽词、搜索、添加和删除。长按视频可不再显示当前视频，不重载整个列表。
- **搜索与登录**：多类型搜索；扫码、短信、密码及 Cookie 导入登录。
- **视频播放**：Media3 播放、画质／编码选择、分 P、弹幕、倍速、手势操作和定时关闭。
- **观看历史与续播**：在「我的 → 观看历史」查看 B站账号历史或本机普通视频记录，按日期分组、分页、单条删除及确认清空；普通视频重新打开时可继续上次分 P／进度或从头播放，已看完的记录重新开始。
- **历史搜索与筛选**：支持按标题、UP 主、分 P 名称、BV／AV 号搜索，多关键词同时匹配；账号历史可按全部／视频／番剧影视／图文专栏／直播／其他筛选。紧凑搜索栏和筛选选项随列表滚走，顶部搜索按钮可回顶聚焦输入。本机搜索仅包含当前账号记录；账号搜索在已加载记录中进行，需点击「继续加载更早记录并筛选」查找更早内容，不会在输入时扫描整个账号历史。清空操作仍作用于当前来源的全部历史，不只删除匹配结果。
- **更多历史入口**：专栏与文集文章可进入阅读页，图文通过明确的图文业务 ID 或可信 B站图文链接进入详情，直播可进入对应直播间；直播不是回放，也不会恢复历史直播进度。课程通过明确课时 ID 或可信课程链接进入独立详情，不把 OID／CID／删除 KID 当课程 ID，也不套用普通视频续播。无法识别或缺少资源信息的记录保留明确提示。
- **课程**：「我的 → 课程」支持粘贴完整 B站 `/cheese/play/ss…`／`ep…` 链接或输入 ss课程ID／ep课时ID，查看目录、讲师主页、介绍图片（预览／缩放／保存），播放平台允许的试看或当前账号有权限的视频课时；账号历史增加课程筛选与入口。课程接口、课时 ID 与番剧分离，固定请求账号 Cookie，切账号／换课程／退出隔离旧请求；未购、直播课时、加密播放或目录不完整时明确说明，不绕过权限、不自动连播。目前未接入平台课程搜索、已购列表、购买、评论或资料下载，不解析短链及外部链接。

课程入口新增「最近学习」，按账号隔离（未登录单独保存）的本机课程记录最多保留最近100门，可按课程名、讲师、课时或 ss／ep ID 多关键词搜索、单条删除、确认清空。清空会删除当前账号全部本机课程记录，不仅是搜索结果；不影响普通视频／番剧记录、B站账号历史或课程购买权限。课程详情提供非弹窗「继续上次」按钮，点击后定位上次课时与进度；目录入口不自动开播，明确 ep 链接仍从头播放。当前目录课时／CID／权限变更、已看完或接近结尾的记录不提供续播。实际播放后每5秒、暂停、离页、切课时及退出保存；平台标记的试看或未确认完整播放状态不覆盖完整课时记录。课程记录不上传B站，不受普通视频续播及播放结束策略影响，返回页面不自动恢复播放。

课程匿名联网验证默认跳过；设置 `QBILI_COURSE_LIVE_TEST=1` 后运行 `testDebugUnitTest --tests "*CoursePlaybackApiTest"` 可检查公开课程目录、允许的试看地址与 CDN 范围读取，不读取账号或执行购买／其他写操作。
- **番剧／影视**：搜索结果可进入番剧详情，查看正片及花絮分集，支持 PGC 播放、画质／编码、倍速、弹幕、切集、本集评论、追番／取消追番及本机断点续播；会员试看与地区／购买限制明确提示，不绕过平台鉴权。
- **视频互动**：点赞、收藏、投币、关注、稍后再看和评论／回复等；评论及楼中楼显示用户头像，点击头像或昵称进入个人主页。部分能力受登录方式与接口权限限制。
- **发送弹幕**：普通视频支持滚动／顶部／底部弹幕及白、粉、黄、蓝四色；竖屏在播放设置下进入，全屏通过播放器右上角弹幕按钮进入。发送位置固定为打开输入框时的当前分 P 进度，支持预览与最多 100 字；需要登录且 Cookie 包含 CSRF。失败保留草稿、不会自动重发，账号或分 P 切换清除旧输入；等级、颜色权限、频率和审核以 B站服务端为准，不伪造即时上屏。暂未扩展到番剧、直播或高级弹幕。
- **相关推荐与分 P 导航**：普通视频详情下方显示 B站 Web 相关推荐，卡片可进入视频、UP 名称可进入主页；列表一次加载、可刷新和重试，失败不影响播放且保留已有推荐，切视频／账号隔离旧请求。仅展示普通稿件，过滤番剧跳转、不可见与重复条目，不伪造分页；首页屏蔽词仍只作用于首页。详情选集区及全屏控制区提供上一 P／下一 P，首末不循环，切换从目标 P 起点播放；默认不自动连播，不自动跳转推荐视频。
- **普通视频播放模式**：在「设置 → 播放与历史」或视频详情的「播放模式」选择播完暂停、单 P 循环、自动下一 P，选择保存在本机且默认播完暂停。自动下一 P 只在当前稿件内按原顺序切换，最后一 P 停止；定时关闭优先。离开播放页、切换账号、暂停或加载失败后不会自动连播，切流隔离旧结束事件；不扩展到番剧、直播或相关推荐。
- **UP 主空间**：个人资料、动态、视频投稿和独立图文栏目。
- **关注动态筛选**：点击动态卡片的头像或昵称进入 UP 主页；顶部「按 UP 筛选」可搜索昵称／UID并分页加载关注列表，选择后独立分页读取该 UP 的动态，点击「全部动态」恢复关注流。切换账号清空旧筛选和列表。
- **动态视频标识**：视频动态显示「视频动态」标签，16:9 封面带播放图标及接口返回的时长，标题单独展示；点击整张卡片进入视频。图文图片仍支持独立点击预览，不显示视频标识。
- **转发动态**：转发者的头像、昵称和说明独立显示，原动态以嵌套引用呈现，保留原作者及正文／视频／图片；点击不同作者头像可分别进入主页，视频与图文入口指向原内容而不是转发 ID。多层转发最多展示三层引用，原动态删除、不可见或结构缺失时明确提示。
- **私信体验**：会话缺少昵称／头像时补查用户资料；查询失败保留 UID 并标记资料不可用，刷新可重试。聊天显示双方头像、居中的时间分组与可复制文字，点击头像进入主页；更早消息加载和失败重试保留原游标，输入栏避开键盘及系统栏。切换账号或会话会取消旧请求，旧结果不能覆盖新页面和草稿。
- **私信图片与表情**：图片及自定义表情消息显示可信 B站图床图片，点击使用统一预览器缩放、切图及保存；撤回消息隐藏原内容。缺少图片地址、非可信图床与未支持消息类型明确占位，不把原始 JSON 显示给用户。当前仍仅支持发送文字，不发送图片／表情，不自动轮询或标记已读。
- **私信分享卡片与通知**：分享消息、视频／专栏推送及直播等分享显示标题、可信图床封面、作者、摘要和 UP 赠言，点击卡片可进入已有视频、专栏、图文、直播、番剧／影视或个人主页页面；通知显示正文模块与站内按钮，系统提示居中显示。会话列表也显示分享标题。仅使用明确业务 ID 或精确站内 HTTP(S) 链接，暂不解析短链、外链和客户端协议；动态 ID 不推测为图文 ID，单集 ep ID 不推测为番剧 season ID，未知目标明确提示暂不支持。撤回消息不保留卡片或跳转入口。
- **图文与专栏**：图文／专栏富文本阅读，支持标题、列表、引用、代码及表情；图片点击预览、双指缩放、双击放大、上下张切换与下载保存，动态图片使用同一预览器；支持评论、点赞和收藏。
- **其他模块**：热门／排行榜、收藏夹、稍后再看、私信和直播。
- **热门栏目**：综合热门支持下拉刷新、滚动分页和失败重试；每周必看默认加载最新已发布期数，可按期数／日期／主题搜索往期；入站必刷展示经典精选；排行榜支持全站及动画、音乐、游戏等投稿分区，排名置于封面角标。卡片显示时长、播放／弹幕数和精选理由，点击 UP 名称进入主页，提供回到顶部按钮。榜单不是个人推荐，其他栏目不伪造分页；暂不包含全站音乐榜。接口风控或数据缺失时明确提示，可手动重试。
- **番剧影视榜**：「热门 → 番剧影视」提供番剧、国产动画、电影、电视剧、纪录片与综艺正片榜，可切换近3日／近7日。卡片显示平台排名、封面及实际返回的评分、更新进度、权限标签和播放／追看数，缺失字段不推测；点击按 season ID 进入已有详情，复用选集、追番和本机续播。榜单不代表播放授权，会员／付费／地区限制仍以详情与播放接口为准；切换榜单取消旧请求，刷新失败保留旧列表，支持手动重试。

番剧影视榜兼容平台返回的「8.8分」字符串、数字及评分对象；空评分或异常评分仅隐藏该作品评分，不阻断整个榜单。匿名联网诊断默认跳过，设置 `QBILI_SEASON_RANKING_LIVE_TEST=1` 后运行 `testDebugUnitTest --tests "*SeasonRankingApiTest"`，可检查六类正片榜近3日／近7日完整列表的真实解析，不读取账号凭据或执行写操作。
- **关于与更新**：在「我的 → 设置 → 关于」查看应用介绍、当前版本、GitHub 主页、开源协议与免责声明；手动检查 GitHub 最新正式发布版本，有更新时提供匹配安装类型的 APK 下载链接。
- **主题选择**：在「我的 → 设置 → 主题选择」切换跟随系统、清爽白或深色；立即生效并在本机保存。清爽白使用白色卡片、浅灰背景和粉色／蓝色点缀，系统浅色也采用此配色。

清爽白采用「灰色背景衬托白色内容」的层级：动态、评论、收藏夹、稍后再看、个人页与设置选项等聚焦区域使用纯白；选中状态通过文字、图标和边框点缀，不再把内容卡片填成灰色。图片占位、分隔线与次要说明仍保留中性灰，播放器和图片预览维持黑色背景。

「我的」页面整体、资料与菜单使用白色；UP 主页顶部资料与栏目入口使用白色，中间以灰色间隔分区。深色主题继续使用对应的深色内容底，不强制填白。

浅色白底内容的默认文字、菜单图标和动态正文使用深色，动态作者昵称不再显示粉色；操作按钮及选中状态仍可使用品牌点缀色。

上述模块均有代码实现，但不代表与官方客户端完全一致，也不保证所有账号、内容和网络环境下均可用。

图文正文使用与专栏一致的排版渲染，已完整解析的正文不再显示「在 B站打开完整图文」，遇到未知或缺失结构则明确提示并保留回退入口。图片保存保持原始文件字节，支持 JPEG／PNG／GIF／WebP／AVIF（显示能力以系统支持为准），单张最多 50MB；Android 10 及以上保存至相册 `Pictures/QBili`，Android 8／9 通过系统文件选择器选择保存位置，不申请广泛存储权限。仅支持 B站图床图片，下载请求不携带账号 Cookie。

图片预览的保存成功／失败提示悬浮在底部切图按钮上方，并避开系统栏与屏幕缺口，不再占用图片的纵向布局。预览器始终保持黑色背景，便于查看图片。

番剧播放进度只保存在本机（最近 100 部），不上传或同步到 B 站观看历史；试看不会覆盖正片续播进度。未开播、地区限制、会员或付费剧集以平台实际返回的权限和播放地址为准。

普通视频进度与本机历史按账号隔离，未登录记录独立保存，最多保留最近 500 条。在「我的 → 设置 → 播放与历史」管理断点续播及普通视频历史同步。**同步默认关闭**，开启需确认；仅在登录并实际播放时上传当前视频、分 P 和播放进度，不补传旧记录，失败不会中断播放。关闭此开关不会删除已上传记录，也不会修改 B站官方历史暂停设置。账号历史可打开普通视频、番剧／影视、专栏／文集文章、可识别图文及直播间，其他类型显示提示但仍可删除。

普通视频的续播不再弹出确认窗口：打开后正常从该分 P 的开头播放，视频左侧显示「继续上次」按钮，点击跳至记录进度，也可关闭此提示；无效或已看完进度不显示按钮。返回播放页外时立即暂停并解绑画面，离开页面后旧播放请求不能恢复播放。

删除／清空本机历史只影响当前账号的本机普通视频记录；删除／清空账号历史会操作当前 B站账号并移除对应本机普通视频进度。番剧独立续播存储不受普通视频本机历史清空影响。

番剧匿名联网诊断默认跳过，可在本机设置 `QBILI_PGC_LIVE_TEST=1` 后运行 `testDebugUnitTest --tests "*SeasonPlaybackApiTest"`，验证公开剧集播放地址、CDN 可读取性及会员试看标记；不会执行追番等账号写操作。

### 推荐来源与屏蔽的边界

默认使用网页端，切换的是 B 站实际推荐接口，不是修改其服务端算法。网页端使用 Cookie 登录身份；App 端必须使用本项目短信登录获得的 `access_key`，请求前通过 OAuth 接口验证账号与有效期，签名身份与短信登录保持一致。扫码、Cookie 和当前网页密码登录没有 App 凭据，选择 App 推荐时会提示重新短信登录或切回网页端，**不会静默使用游客推荐**；真正未登录时才显示明确标注的游客推荐。登录／退出／更换账号会清空旧推荐重新请求，不保证与官方 App 展示完全一致。

首页会分页读取当前账号的完整 B 站黑名单，与本机 UP 屏蔽规则合并，对网页和 App 推荐均生效；下拉刷新重新同步。黑名单同步失败、身份校验失败或 UP 身份无法确认时不会放行未校验的视频。标题、Tag、频道与单个视频屏蔽仍在本机生效。

App 推荐匿名联网诊断默认跳过；设置 `QBILI_FEED_LIVE_TEST=1` 后运行 `testDebugUnitTest --tests "*AppFeedApiTest"` 可验证签名、真实卡片解析及返回游标分页，不读取账号凭据或执行写操作。

“不感兴趣”、标题、Tag 和频道屏蔽在本机过滤推荐，不会提交到 B 站官方推荐算法。通过菜单拉黑 UP 会同步到 B 站账号；在设置中移除本地 UP 屏蔽不会自动取消账号拉黑，仍在官方黑名单中的 UP 仍会被过滤。

## 开发环境

| 项目 | 版本／要求 |
| --- | --- |
| Android | Android 8.0（API 26）及以上 |
| Compile / Target SDK | 35 |
| JDK | 17 |
| Gradle | 8.10.2 |
| Android Gradle Plugin | 8.8.2 |
| Kotlin | 2.1.0 |

安装 Android SDK Platform 35，并在 Android Studio 中配置 Gradle JDK 为 17，或将本机 `JAVA_HOME` 指向 JDK 17。SDK 路径可通过 Android Studio 自动生成的 `local.properties` 或 `ANDROID_HOME` 配置；不要提交自己的 `local.properties`。

## 构建与测试

克隆仓库并进入项目目录：

```bash
git clone https://github.com/Gordenghost/QBili.git
cd QBili
```

### Gradle Wrapper

macOS / Linux：

```bash
./gradlew testDebugUnitTest --console=plain
./gradlew assembleDebug --console=plain
```

Windows PowerShell：

```powershell
.\gradlew.bat testDebugUnitTest --console=plain
.\gradlew.bat assembleDebug --console=plain
```

Wrapper 使用官方 Gradle 8.10.2 分发包，并配置 SHA-256 校验。若网络超时或本地 Wrapper 缓存异常，可直接使用自行安装的 **Gradle 8.10.2**，不要为绕过下载问题取消校验。

### 本地 Gradle 备用方式

已将 JDK 17 和 Gradle 8.10.2 配置到环境变量时：

```powershell
gradle compileDebugKotlin --console=plain
gradle testDebugUnitTest --console=plain
gradle assembleDebug --console=plain
```

也可以调用本机 Gradle 的完整路径，并通过 `-Dorg.gradle.java.home=本机JDK17目录` 指定 JDK。此类绝对路径仅用于本机命令或用户级 Gradle 配置，不写入仓库的 `gradle.properties`。

### 国内网络与依赖镜像

清理 Gradle 缓存后，可以联网重新下载依赖，不要使用 `--offline`。如果只能访问国内网络，可通过 `dependencyMirror` 选择国内 Maven 镜像，插件和应用依赖都会一起切换：

```powershell
gradle -PdependencyMirror=aliyun --refresh-dependencies testDebugUnitTest assembleDebug --console=plain
```

- `aliyun`：阿里云的 Google、Maven Central 和 Gradle 插件镜像，使用 `https://maven.aliyun.com/repository/google`、`https://maven.aliyun.com/repository/central` 和 `https://maven.aliyun.com/repository/gradle-plugin`。
- `huawei`：华为云 Maven 聚合镜像，使用 `https://repo.huaweicloud.com/repository/maven/`；阿里云不可用时，将命令参数改成 `-PdependencyMirror=huawei` 重试。
- `official`：默认值，保留官方 Google、Maven Central 和 Gradle 插件仓库。不传参数或指定 `-PdependencyMirror=official` 即恢复官方源。

镜像模式只配置所选国内仓库，不再回退国外仓库。镜像由第三方维护，可能同步延迟或缺少特定构件；仓库地址配置完成不代表依赖已下载或构建通过。全局 Gradle 初始化脚本也可能覆盖仓库配置。

该开关只影响 Maven 依赖，不影响 Gradle Wrapper 分发包或 Android SDK 下载。国内网络下优先使用已经安装的 Gradle 8.10.2，并提前准备 JDK 17 与 Android SDK Platform 35、所需 Build Tools。保留现有版本、HTTPS 和 Wrapper SHA-256 校验，不因镜像问题降低版本或关闭校验。

首次下载或切换镜像时可使用 `--refresh-dependencies`；缓存齐全后无需每次添加。若提示 `SocketException: Permission denied`，需先解除当前执行环境的联网限制，仅更换镜像不能解决网络权限问题。

### 受限环境的离线构建

如果普通终端能构建，而受限执行环境无法联网，可先在普通终端下载依赖到项目内缓存，随后使用同一目录离线构建。两次构建必须选择同一镜像，否则已有缓存可能无法解析。

普通终端准备缓存（JDK 17 和 Gradle 8.10.2 已配置）：

```powershell
gradle --gradle-user-home app/build/local-gradle-home -PdependencyMirror=aliyun testDebugUnitTest assembleDebug --console=plain
```

缓存齐全后，在受限环境执行：

```powershell
gradle --gradle-user-home app/build/local-gradle-home --offline -PdependencyMirror=aliyun '-Pkotlin.compiler.execution.strategy=in-process' --no-daemon testDebugUnitTest assembleDebug --console=plain
```

`--no-daemon` 只控制 Gradle，不会禁用 Kotlin 编译守护进程。如果日志出现 `AccessDeniedException` 并指向用户目录下的 `kotlin/daemon`，进程内编译参数可避免启动该独立守护进程；此参数仅用于受限环境，不改变普通开发的默认配置。PowerShell 中带点的 `-P` / `-D` 参数需要加引号，避免被拆成任务名。缓存位于已忽略的构建目录，执行 `clean` 或手动清理该目录后可能需要重新下载依赖；离线模式不能补齐缺失依赖。

### APK 与版本号

- Debug APK：`app/build/outputs/apk/debug/app-debug.apk`。
- Debug 包名：`com.qbili.debug`；通常只能覆盖包名与签名均相同的旧版。不同开发者生成的 debug 签名可能不同，不能保证相互覆盖安装。
- 发布更新前需与上一正式 Release 比较 APK 签名。原 debug 密钥可通过本机命令参数 `'-Pqbili.debugKeystore=本机密钥路径'` 指定；仅适用于原标准 Android debug 密钥，路径不写入共享配置，密钥不得提交。不能以重新生成的密钥冒充可覆盖安装的更新。
- Release 尚未配置签名，未签名产物不能直接用于安装分发；不要上传签名密钥或密码。
- `version.properties` 中的 `baseVersion` 是基础版本，`buildNumber` 在每次执行 `preBuild` 时自动递增。`versionName = baseVersion.buildNumber`，构建日志显示本次 `versionCode`。测试任务若触发 `preBuild`，也可能推进版本号。
- APK、构建目录、缓存和日志不会作为源码提交。仓库创建本身不代表已经发布 GitHub Release。

### 检查更新与发布约定

- 下载已发布 APK：https://github.com/Gordenghost/QBili/releases 。
- 应用只在用户点击「检查更新」时匿名请求 GitHub Releases API，不携带 B 站 Cookie 或访问令牌，不在后台检查或自动下载安装。
- 版本按三段数字比较，仅提示更新的正式版本，不提示降级或预发布版本。无版本、网络异常和 GitHub 限流分别给出提示；没有匹配 APK 时提供对应 Release 页面。
- APK 附件建议命名为 `QBili-版本号-debug.apk`（例如 `QBili-0.2.235-debug.apk`），也兼容 `app-debug.apk`。正式签名构建对应 `-release.apk`；不要把未签名的 Release 构建当作可安装更新发布。
- 推送源码不会自动生成 APK 或 GitHub Release；只有发布新的正式 Release 并上传相应 APK 后，应用才会检测到可下载更新。不同签名的包不能直接覆盖安装。

## 项目结构

```text
app/src/main/java/com/qbili/
├── ui/       Compose 页面、组件、导航与 ViewModel
├── domain/   领域模型及播放器等纯逻辑
```

- 本项目不承诺不会触发账号风控，不保证登录态持续有效；请自行评估账号与隐私风险。
